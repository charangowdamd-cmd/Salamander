# Salamanders Product Roadmap

This document outlines the development milestones and strategic feature roadmap for the Salamanders platform.

---

## 🎯 Phase 1: MVP & Core Evaluation (Completed ✅)
- [x] Next.js 14 App Router scaffold with Tailwind CSS & TypeScript.
- [x] Interactive Silk WebGL2 hero canvas background.
- [x] Monaco code editor integration with custom testcase console.
- [x] Multi-language execution judge (Node.js & Python 3) with security screening.
- [x] Tiered AI mentorship integration using Google Gemini 2.5 Flash.
- [x] Supabase Auth & PostgreSQL schema with Row-Level Security (RLS).
- [x] Verified developer profile at `/u/[username]` with dynamic SVG badge generation.
- [x] LeetCode-grade analytics card: circular acceptance gauge & 52-week calendar heatmap.

---

## 🚀 Phase 2: Enhanced Assessment & Sandbox Hardening (In Progress 🔄)
- [ ] Containerized microvm sandboxing (Docker / gVisor) for compiled languages (C++20, Java 21, Rust).
- [ ] Timed mock interview evaluation rubric with automated time-complexity penalties.
- [ ] Real-time peer code pair-programming rooms using WebRTC or Supabase Realtime.
- [ ] Daily placement streak notifications and calendar sync.

---

## 🌟 Phase 3: Placement & Campus Ecosystem (Planned 📋)
- [ ] University & college leaderboards with student verification.
- [ ] Company-specific mock assessment generator mirroring actual Google, Amazon, and Microsoft hiring bars.
- [ ] Automated resume ATS scanner matching solved problem tags to job descriptions.
- [ ] Exportable PDF verified interview readiness certificates.
